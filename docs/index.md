# Laravel Activity Log UI — Documentation

A beautiful, drop-in Tailwind CSS dashboard for [Spatie Laravel Activitylog](https://spatie.be/docs/laravel-activitylog). Browse, filter, diff, analyse and export your audit trail — with analytics charts, a timeline, saved views, dark mode and a read-only JSON API. No build step.

## 60-second start

```bash
composer require nsd7/laravel-activitylog-ui
```

Visit `/admin/activity-log` while logged in. Everything else is optional — publish the config to customise the prefix, middleware, exports and feature toggles.

> Looking for the source, issues or releases? See the [GitHub repository](https://github.com/nowshad7/laravel-activitylog-ui).
